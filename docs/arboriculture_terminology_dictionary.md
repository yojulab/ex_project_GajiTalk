## 1. 수목 구조 및 골격 기본 용어 (Tree Structure & Framework)

| 표준 용어 (현장어) | 영문 표기 | 정의 및 AI 비전 세그멘테이션 기준 |
| :--- | :--- | :--- |
| **주간 (원줄기, 몸통)** | Main Trunk / Leader | 뿌리에서부터 수관 꼭대기까지 중심을 이루며 올라가는 기둥 줄기. 절단 금지 핵심 보존 영역. |
| **주지 (원가지, 1차 가지)** | Primary / Scaffold Branch | 주간에서 직접 갈라져 나와 수형(나무 모양)의 기본 뼈대를 형성하는 굵은 가지. |
| **부주지 (덧가지, 2차 가지)** | Secondary Branch | 주지에서 갈라져 나와 수관의 폭과 볼륨을 채우는 가지. |
| **측지 (곁가지, 잔가지)** | Lateral Twig | 부주지에서 뻗어 나와 잎과 꽃눈(화아)이 맺히는 세밀한 가지. |
| **수관 (나무갓)** | Crown / Canopy | 나무의 가지와 잎이 모여 이루는 전체 외형(구름형, 원추형, 자연형 등). |
| **수고 / 수관폭** | Tree Height / Crown Width | 지표면에서 수관 최상단까지의 높이(m) 및 좌우 너비(m). **조경사 시공 견적 단가 산출의 제1 기준**. |
| **지융부 (가지턱)** | Branch Collar | 원줄기(주간/주지)와 곁가지가 만나는 밑동의 볼록하게 융기된 조직. 상처 치유(캘러스 형성)의 핵심 부위. |
| **외아 (바깥눈) / 내아 (안쪽눈)** | Outer Bud / Inner Bud | 가지의 바깥쪽을 향한 눈(외아)과 수관 안쪽을 향한 눈(내아). 전지 시 외아 위에서 잘라야 가지가 바깥으로 뻗음. |

## 2. AI 비전 판별 필수 제거 대상 가지 ("7대 기피 가지 / 불필요 가지")

AI 시뮬레이터(`BranchOverlayCanvas`)와 `pruning_simulations.cuttingGuides`에서 최우선 탐지·마킹해야 하는 절단 대상 가지 분류입니다.

| 가지 유형 (`branchType`) | 우선순위 (`priority`) | 시각적 특징 및 문제점 | 표준 절단 가이드 (`reason` / `expectedEffect`) |
| :--- | :---: | :--- | :--- |
| **1. 도장지 (웃자란 가지)**<br/>(Water Sprout) | `HIGH` | 기존 수관 라인을 뚫고 수직으로 급격히 웃자란 가지. 양분을 독점하고 수형을 무너뜨림. | **기부(밑동)에서 바짝 솎아내기**. 양분 분산을 막고 목표 수관 윤곽을 단정하게 유지합니다. |
| **2. 내향지 (안쪽 자람 가지)**<br/>(Inward Branch) | `HIGH` | 수관 바깥이 아닌 나무 중심부(주간 쪽)를 향해 거꾸로 자라는 가지. 통풍과 채광을 차단함. | **발생 기점에서 완전 제거**. 수관 내부 채광과 통풍이 개선되어 병충해를 예방합니다. |
| **3. 교차지 (얽힌 가지)**<br/>(Crossing Branch) | `HIGH` | 다른 가지와 X자로 겹치거나 마찰을 일으키는 가지. 바람에 쓸려 수피 손상 및 부패 유발. | **두 가지 중 세력이 약하거나 방향이 나쁜 가지를 제거**. 가지 간 마찰 상처와 수피 괴사를 방지합니다. |
| **4. 하향지 (처진 가지)**<br/>(Drooping / Downward Branch) | `MEDIUM` | 아래쪽으로 힘없이 처져 자라는 가지. 수세를 약화시키고 통행을 방해함. | **수평 분기점 또는 밑동에서 절단**. 나무 하단 시야가 시원해지고 상부 수세가 강화됩니다. |
| **5. 병충해·고사지 (죽은 가지)**<br/>(Dead / Diseased Branch) | `HIGH` | 말라 죽었거나 병해충에 감염된 가지. 2차 감염원 및 낙하 위험. | **지융부(Branch Collar)를 남기고 즉시 제거 후 절단면 도포제 처리**. 전염 차단 및 새살(캘러스) 회복 유도. |
| **6. 평행지 (중복 가지)**<br/>(Parallel Branch) | `MEDIUM` | 같은 방향으로 위아래 나란히 겹쳐 자라는 가지. 아래쪽 가지의 햇빛을 가림. | **간격을 고려해 한쪽 가지를 솎아내기**. 층간 채광을 균일하게 확보하여 고른 생장을 유도합니다. |
| **7. 맹아지 / 흡지 (밑동 움가지)**<br/>(Sucker) | `MEDIUM` | 뿌리 근처나 주간 하단부에서 올라오는 잔가지. 원줄기 생장력을 빼앗음. | **발견 즉시 지면/주간 가까이에서 제거**. 주간과 상부 수관으로 양분 공급을 집중시킵니다. |

## 3. 전지·조경 시공 기법 전문 용어 (Pruning & Landscaping Techniques)

| 기법 용어 | 영문 / 한자 | 상세 시공 방법 및 적용 수종 |
| :--- | :--- | :--- |
| **솎아베기 (솎음전정)** | Thinning Cut (疏剪) | 가지의 중간이 아닌 **분지점(밑동)에서 통째로 잘라내는 기법**. 수관 내부 통풍·채광 개선에 필수. |
| **자르기 (절단전정 / 다듬기)** | Heading Cut (截剪) | 가지의 중간(바깥눈 바로 위)을 잘라 길이를 줄이고 곁가지 분지를 유도하는 기법. |
| **적심 (순집기 / 새순자르기)** | Pinching / Candle Pruning | **소나무(적송·반송·조형소나무)**에서 봄철(5~6월) 새로 올라온 새순(촛대순)을 꺾거나 잘라 수고 생장을 억제하고 잔가지를 촘촘히 만드는 고급 기법. |
| **잎솎기 (고엽 제거)** | Needle Plucking | 소나무의 묵은 잎을 솎아내어 햇빛 투과율을 높이고 하부 가지 고사를 막는 가을~겨울 전문 작업. |
| **수형 유도 (유인)** | Branch Training / Guying | 철사걸이, 버팀목, 당김줄로 가지의 각도와 방향을 잡아 구름형·현애형 등 명품 수형을 만드는 작업. |
| **강전정 / 약전정** | Heavy / Light Pruning | 겨울철 휴면기에 굵은 골격 가지를 정리하는 강전정과, 생육기에 잔가지·도장지만 다듬는 약전정. |
| **상처 도포제 (유합제)** | Wound Dressing / Paste | 직경 2cm 이상의 굵은 가지를 자른 단면에 병원균 침투와 수분 증발을 막기 위해 바르는 보호제. |

## 4. 현장 압축 "10대 전지 골든 룰" (10 Golden Rules of Pruning)

모든 AI 전지 시뮬레이션 설명(`reason`, `expectedEffect`) 및 전문가 첨삭 코멘트는 아래 10대 골든 룰을 절대 준수합니다:

1. **[지융부 보존의 원칙]**: 가지를 밑동에서 자를 때는 원줄기 쪽의 볼록한 **'지융부(Branch Collar)'를 절대 훼손하지 않고 남긴 채** 바깥쪽 경계선에서 자른다 (바짝 자르면 썩어들어감).
2. **[바깥눈(외아) 위 사선 절단 원칙]**: 가지를 중간에서 자를 때는 반드시 **바깥쪽을 향한 눈(외아) 위 0.5~1cm 지점에서 눈과 평행하게 45도 사선**으로 자른다 (안쪽 눈 위에서 자르면 내향지가 발생함).
3. **[7대 기피 가지 우선 제거 원칙]**: 수형을 다듬기 전에 **고사지 → 병충해가지 → 교차지 → 내향지 → 도장지 → 하향지 → 평행지** 순서로 불필요한 가지를 먼저 솎아낸다.
4. **[소나무 적심(순집기) 적기 원칙]**: 소나무는 일반 활엽수처럼 아무 곳이나 자르면 눈이 나오지 않고 가지가 죽으므로, 반드시 **5~6월 새순(촛대순) 시기 적심**과 **가을~겨울 잎솎기**로 수형을 관리한다.
5. **[화목류 꽃눈(화아) 보호 원칙]**: 봄꽃 나무(매화, 벚나무, 산수유, 철쭉)는 **꽃이 진 직후(5~6월)**에 전지하고, 여름꽃 나무(배롱나무, 무궁화, 수국)는 **겨울~이른 봄 휴면기**에 전지하여 꽃눈이 잘려나가는 것을 막는다.
6. **[1회 엽량 30% 이내 절제 원칙]**: 한 번의 가지치기에서 나무 전체 잎 면적의 **30% 이상을 과도하게 제거하지 않는다** (과도한 강전정은 수세 쇠약 및 다량의 도장지 폭발을 유발함).
7. **[수관 내부 투광·통풍 확보 원칙]**: "새가 수관 사이를 날아 통과할 수 있을 정도"로 내부 잔가지(내향지·교차지)를 솎아내어 햇빛과 바람이 골고루 통하게 한다.
8. **[상강하약(上強下弱) 제어 원칙]**: 나무는 꼭대기(정부우세성)와 바깥쪽 세력이 강해지고 아래쪽 가지가 약해져 고사하기 쉬우므로, **상부 세력은 강하게 억제(강전정)하고 하부 가지는 보호(약전정)**하여 균형을 맞춘다.
9. **[굵은 가지 3단 절단 원칙]**: 무거운 큰 가지를 한 번에 자르면 무게로 인해 줄기 껍질(수피)이 찢어지므로, 반드시 **밑면 베기 → 윗면 절단 → 지융부 마감 절단의 3단 절단법**을 적용한다.
10. **[절단면 소독 및 유합제 도포 원칙]**: 병든 가지를 자른 가위는 반드시 알코올 소독 후 다음 나무에 사용하며, **직경 2cm 이상 절단면에는 즉시 상처 도포제(톱신페스트 등)를 발라** 부후균 침입을 차단한다.

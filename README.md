## 🏛 서비스 아키텍처 및 할당 포트

모든 웹·앱·백엔드 서비스는 **`./apps/` 하위 디렉토리**로 격리되어 독립된 환경을 유지하며, 지정된 고정 포트를 엄격히 준수합니다:

```
apps/ex_project_GajiTalk/
├── apps/
│   ├── mobile-app/          # [Port 30018] 정원주 & 조경사 모바일 웹/앱 (React + Vite)
│   ├── admin-web/           # [Port 30019] 통합 관리자 웹 & 첨삭 스튜디오 (React + Vite)
│   └── backend/             # [Port 30020] RESTful API & AI/매칭 서버 (Node.js + Express)
├── backend -> apps/backend  # 루트 단축 심볼릭 링크
├── generate_env.sh          # 운영 서버용 4대 .env 일괄 자동 생성기
├── init_db.sh               # ./backend/.env 설정 기반 운영 DB 초기화 및 시딩
├── run_port.sh              # 3대 포트 통합 라이프사이클 관리자
└── tests/                   # Playwright Headless E2E 무인 자동 검증 슈트
```

### 서비스 접속 엔드포인트
- 📱 **모바일 앱 (정원주·조경사 모드)**: `http://localhost:30018` (외부 바인딩 `http://0.0.0.0:30018`)
- 💻 **통합 관리자 웹 & AI 첨삭 스튜디오**: `http://localhost:30019` (외부 바인딩 `http://0.0.0.0:30019`)
- ⚙️ **백엔드 REST API 엔진**: `http://localhost:30020/api` (외부 바인딩 `http://0.0.0.0:30020`)

## 🛠 운영 환경 초기화 스크립트

### 1. 4대 환경 변수(.env) 일괄 자동 생성

[`generate_env.sh`](./generate_env.sh) (심볼릭 링크 [`setup_env.sh`](./setup_env.sh))는 루트 및 하위 3개 서비스의 `.env` 파일을 일괄 생성하며 기존 파일은 자동으로 `.env_backups/`에 백업합니다.

```bash
# [방법 1] 기본 운영 설정으로 즉시 자동 생성
./generate_env.sh

# [방법 2] npm 스크립트로 실행
npm run env:prod

# [방법 3] run_port.sh 명령어로 실행
./run_port.sh env

# [방법 4] 사용자 지정 MongoDB URI 지정
./generate_env.sh "mongodb://admin:admin123@external_project_db_mongo:27017/"

# [옵션] 파일 쓰기 전 내용 미리보기 (Dry-Run)
./generate_env.sh --dry-run
```

**자동 생성되는 4대 환경 변수 파일**:
1. `./.env` (루트 통합 공통 설정)
2. `./apps/backend/.env` (포트 `30020`, MongoDB URI, JWT Secret, Seed 계정 등)
3. `./apps/mobile-app/.env` (포트 `30018`, API Base URL, 지도 기본 좌표)
4. `./apps/admin-web/.env` (포트 `30019`, API Base URL, 모바일 앱 연동 URL)

---

### 2. 운영 데이터베이스 초기값 설정 및 시딩

[`init_db.sh`](./init_db.sh) (심볼릭 링크 [`seed_db.sh`](./seed_db.sh))는 **`./backend/.env` 설정을 엄격히 준수**하여 MongoDB에 5대 핵심 컬렉션 및 표준 기초 데이터를 적재합니다.

```bash
# [방법 1] 초기화 전용 스크립트 실행
./init_db.sh

# [방법 2] npm 스크립트로 실행
npm run db:init
# 또는
npm run seed

# [방법 3] run_port.sh 명령어로 실행
./run_port.sh seed

# [옵션] 실제 DB 수정 없이 설정 정보 사전 확인 (Dry-Run)
./init_db.sh --dry-run
```

**초기화 시 적재되는 데이터셋**:
- **수종 도감 8종**: 소나무(적송/반송/해송), 단풍나무(청단풍/공작단풍), 배롱나무, 향나무, 회양목 등 표준 전지 수종
- **운영 기본 계정**: 통합 관리자, 현장 운영 매니저, 정원주 회원 3명, 조경 명인/의사 4명
- **샘플 정원 및 시뮬레이션**: 양평·파주·성북동 정원, 절단 가이드라인 좌표(`cuttingGuides`), 생장 예측 이미지
- **공간 인덱스**: 조경사 반경 매칭용 `2dsphere` 위치 인덱스 자동 구축

> **안전 가드 탑재**: 사용자가 터미널에서 `. init_db.sh` 또는 `source init_db.sh`로 실행하더라도 격리된 서브쉘로 위임 실행하여 **터미널 창이 꺼지는 현상을 원천 방지**합니다. 또한 바이너리 경로 절대 링크 복원으로 `tsc: not found` 에러가 발생하지 않습니다.

## 🎮 통합 포트 및 서비스 관리자 (run_port.sh)

[`run_port.sh`](./run_port.sh) 스크립트로 전체 프로세스의 기동, 중지, 빌드, 재시작, 상태 점검을 제어할 수 있습니다:

| 명령어 | 축약 명령어 | 설명 |
| :--- | :--- | :--- |
| `./run_port.sh start all` | `./run_port.sh all` | 전체 서비스(`30018`, `30019`, `30020`) 운영 모드 기동 |
| `./run_port.sh dev all` | - | 전체 서비스 개발 모드(HMR) 기동 |
| `./run_port.sh stop all` | - | 가동 중인 모든 서비스 일괄 종료 |
| `./run_port.sh restart all` | - | 전체 서비스 일괄 안전 재시작 |
| `./run_port.sh build all` | `./compile.sh all` | 전체 프로젝트 일괄 컴파일 / 빌드 |
| `./run_port.sh status` | - | 포트 점유 여부, PID, 서비스 접속 URL 점검 |
| `./run_port.sh env` | - | 운영 환경 변수 일괄 자동 생성 (`generate_env.sh` 호출) |
| `./run_port.sh seed` | - | 운영 DB 초기값 설정 및 시딩 (`init_db.sh` 호출) |

> **단일 서비스 제어**: `all` 대신 `30018`(mobile), `30019`(admin), `30020`(backend) 포트 번호를 인자로 주어 개별 제어가 가능합니다. (예: `./run_port.sh start 30018`)

## 🔍 의뢰자 소통용 UI 일련번호 인스펙션 시스템

의뢰자와 개발팀 간에 화면의 특정 요소나 문구를 정확하게 지칭하여 소통할 수 있도록 **UI Inspect 태깅 시스템**이 기본 내장되어 있습니다:

- **단축키 토글**: 화면 아무 곳에서나 **`Alt + I`** 키를 누르면 각 컴포넌트 상단에 고유 일련번호 뱃지가 표시/숨김 처리됩니다.
- **클립보드 자동 복사**: 일련번호 뱃지(예: `[P01-SEC01-BTN01]`)를 클릭하면 아래 4대 핵심 정보가 클립보드에 정돈된 형태로 복사되며 `[Copied! ✓]` 피드백이 표시됩니다:
  1. 고유 일련번호 (`Serial ID`)
  2. 페이지명 (`Page Name`)
  3. URI 경로 (`Route URI`)
  4. 컴포넌트/버튼 명칭 (`Component Title`)

## 🌿 조경·수목 전지 전문 용어 및 10대 골든 룰

본 플랫폼의 모든 AI 시뮬레이션 및 조경사 견적 산출은 [docs/arboriculture_terminology_dictionary.md](./docs/arboriculture_terminology_dictionary.md)의 규격을 준수합니다:

### 7대 기피 가지 (우선 제거 대상)
1. **도장지(웃자란 가지)**: 수형 균형을 깨고 영양분을 독점하는 수직 가지
2. **내향지(역지)**: 줄기 안쪽으로 파고들어 채광과 바람길을 가로막는 가지
3. **교차지**: 인접 주지와 겹쳐 바람에 수피 마찰 상처를 유발하는 가지
4. **하향지**: 지면으로 급격히 처져 활력이 저하된 가지
5. **평행지**: 같은 방향으로 나란히 뻗어 서로를 가리는 가지
6. **움가지(맹아지)**: 지제부(뿌리목)나 줄기 밑동에서 돋아난 불필요한 잔가지
7. **고사지 / 병충해가지**: 마르거나 병균·해충에 감염된 가지

### 현장 압축 10대 전지 골든 룰
1. **지융부(Branch Bark Ridge) 보존**: 줄기에 바짝 붙이거나 그루터기를 남기지 않고 지융부 바로 바깥을 절단합니다.
2. **외아(Outward Bud) 위 45도 사선 절단**: 가지 바깥쪽을 향한 눈 상단 5~10mm 지점을 사선으로 잘라 수관 중심을 비웁니다.
3. **1회 엽량 절제 한도 30% 엄수**: 1회 전지 시 전체 잎의 30% 이상을 잘라내지 않아 수세 쇠락을 방지합니다.
4. **굵은 가지 3단계 절단법**: 가지 찢김을 막기 위해 하부 칼집(1) → 상부 절단(2) → 그루터기 정밀 절단(3)을 적용합니다.
5. **소나무 봄철 적심(순집기)**: 5~6월 길게 솟은 촛대순의 1/2~2/3를 손으로 꺾어 운두를 치밀하게 다듬습니다.
